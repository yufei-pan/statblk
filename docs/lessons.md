# Lessons

What this project's past changes taught us. Read all of this before changing an API, a format or an
agreed behaviour here. For the full story of a line, find the entry with the same date and name in
`lessons-full.md`.

When one has to change, add the full entry to `lessons-full.md` and one line here, newest last, in the
same commit as the change. Never merge lines to save space; before this file passes 80 KB (what one
Claude Code read returns, measured 2026-11-15), ask the user.

- **2026-11-14 statblk 1.62: a copy you carry is no requirement**: declare only what the program needs from outside it. A library it embeds and picks by version at import needs no install requirement, and one left behind guarantees nothing while the installer's own failures (pip 9 upgrading an old multiCMD, `DuplicateOptionError`) stop your install.
- **2026-11-14 statblk 1.62: a source the timeout cut is named, and a check it hid is unknown**: read the exit status of every command whose output fills the result, not only its output; one stopped part way is named where the operator reads (stderr, after the table), with what it leaves missing, and a health check counts what the cut could hide from it as "could not tell", never as healthy; a cut that hides nothing it reads leaves a healthy run's answer and silence as they were.
- **2026-11-16 statblk 1.63: a filter drops a row only on a value that was read**: a value whose source did not answer (not run, stopped, failed, silent on that item) is not zero or blank, so the row stays with the cell blank; a check over the rows then needs no second path guessing what the filters dropped, beyond the two facts the rows cannot show (what `mount` listed, what a pattern would have matched). 1.63 applies it to a stopped or missing command and to `statvfs`; 1.64 finished it.
- **2026-11-20 statblk 1.64: not answering is one state, whatever the cause**: a command that was stopped, was not found or failed did not answer; record that once, where its output is read, with its own exit status, and let the health check and the notes read that one record (`-F` too; no `-F`, `-A` or size filter drops a row on a value it did not read; a pattern can, since it is matched against what was read). A cause found apart (a `which()` up front, a list for one exit code) is a second path that the next cause misses, and a value read from a source that did not answer (a size, a throughput) is not 0 either.
- **2026-11-23 statblk 1.65: a check left nothing to judge could not tell**: a health check says "healthy" only when its table gave it a row and a checked column to judge, and it knows that from the table it judged, not from what the arguments would leave; it answers "could not tell" (exit 3) with why on stderr when no row is left (a filter, a typo, a host where no device is listed or shown) or no checked column is. That is all 1.65 guarantees: a row whose checked cells are both blank still counted as healthy (1.66 settles it, below). Guessing from the filters (probing a pattern with `''` and `'a'`) was wrong both ways: `-v '.+'` keeps no row (NAME is never blank) and passed, `-v '^$|a'` can keep rows and was refused.
- **2026-11-23 statblk 1.66: a name filter matches the name the operator reads**: an option that filters by name matches the name as the tool shows it (`sda`, `pve-root`) as well as every form it matched before (the path), so a pattern that matched still matches and one typed from the table finds its row; with `-v` a wider match drops more rows, which the upgrade note says. 1.65 matched only the path the code iterates, so `-D '^sda$'` found nothing (and `--check` exited 3).
- **2026-11-23 statblk 1.66: a check is healthy only where it judged a value**: a row counts as judged only when one of its checked cells holds a value; a table with rows but no value in a checked column (unmounted virtual devices only, `-x SMART` with nothing mounted) could not tell (exit 3, with why), as a table with no row could not. A blank that means "nothing to check here" (a virtual device's SMART) is healthy for the row and judges nothing for the run.
