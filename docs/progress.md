Written in 1.63's fix round, its approved field naming C78. The question as asked: **A disk the system reports with zero size (from 1.62's last review, a second-opinion lead; not your words).** statblk hides a zero-size device by default, so `statblk --check` does not judge its SMART; `--check --show_zero_size_devices` does. A dead disk that reads zero size therefore passes a plain `--check` (reproduced with fake commands only, not on a real disk). Options: **(1) keep it: a known limitation, with one README line (recommended)**, revisited when someone sees it on a real disk or measures what smartctl answers for one; (2) `--check` always judges zero-size hardware devices: closes it, but a host with an empty card-reader slot or empty virtual-media drive would exit 3 until the operator filters it (expected, not measured). Waits on it: only that limitation's text; 1.63 builds without it, and the case stays in a narrowed deferred entry until you answer.
